# Ontario Plumbing

A modern, responsive website for a professional plumbing company serving homeowners and businesses across Ontario.

The website is designed to make it easy for visitors to understand the company's services, build trust through customer reviews, find their service area, and request plumbing services.

## Pages

- Home
- About
- Services
- Reviews
- Contact
- 404 Not Found

## Features

- Responsive design for mobile and desktop
- Service information and service areas
- Customer reviews and ratings
- Contact and quote request form
- Responsive navigation
- Reusable UI components
- Smooth animations and transitions
- Custom 404 page

## Built With

- React
- TypeScript
- Vite
- Tailwind CSS
- React Router
- Motion
- Embla Carousel
- Lucide React
- React Icons

## Getting Started

Clone the repository and install the dependencies:

`bash
pnpm install

Start the development server:
pnpm dev

The application will be available at the local development URL provided by Vite.

Production Build
To create a production build:
pnpm build

To preview the production build locally:
pnpm preview
